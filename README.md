# Amirelle

Amirelle dresses you from clothes that actually exist, for the thing you are actually doing today.

India-first style desk. Not a chatbot. Not a Pinterest clone.

## Run

```
npm ci
npm run dev
```

Opens on `0.0.0.0:8080`.

## Note

Checkout is off. Closet and photos stay in the browser. Account holds email, birth, gender, city.
